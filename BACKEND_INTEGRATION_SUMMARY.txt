================================================================================
  ENVIRONMENT VARIABLES REQUIRED FOR DEPLOYMENT
================================================================================

REQUIRED (All 4 must be set):

1. DATABASE_URL
   Source: Neon dashboard
   Format: postgresql://user:password@host.neon.tech/database
   Purpose: PostgreSQL connection string
   
2. JWT_SECRET
   Source: Run: openssl rand -base64 32
   Format: Base64 encoded string (32+ characters)
   Purpose: Sign and verify JWT tokens
   
3. STRIPE_SECRET_KEY
   Source: Stripe dashboard → API Keys
   Format: sk_test_... or sk_live_...
   Purpose: Stripe payment processing
   
4. STRIPE_WEBHOOK_SECRET
   Source: Stripe dashboard → Webhooks → Signing secret
   Format: whsec_...
   Purpose: Verify webhook authenticity

OPTIONAL:

- NODE_ENV: Set to "production" (auto-set by platforms)
- PORT: Server port (default: 8080)
