🔐 ENVIRONMENT VARIABLES YOU NEED
═══════════════════════════════════════════════════════════════════════════

Required (all 4 must be set):

  DATABASE_URL
    Where: Neon dashboard → Connection
    Format: postgresql://user:password@host.neon.tech/database
    Why: Connect to your database

  JWT_SECRET
    Where: Generate with: openssl rand -base64 32
    Format: Base64 string (32+ characters)
    Why: Sign authentication tokens

  STRIPE_SECRET_KEY
    Where: Stripe dashboard → API Keys
    Format: sk_test_xxxxx or sk_live_xxxxx
    Why: Process payments

  STRIPE_WEBHOOK_SECRET
    Where: Stripe dashboard → Webhooks
    Format: whsec_xxxxx
    Why: Verify webhook authenticity
